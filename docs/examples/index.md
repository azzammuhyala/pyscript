# Examples
Beberapa contoh kode PyScript tersedia di folder `examples` pada repositori PyScript. Klik
[disini](https://github.com/azzammuhyala/pyscript/tree/main/examples) untuk melihatnya.

Saya juga membuat proyek cukup besar yang menggunakan bahasa ini bernama
[fnftaki](https://github.com/azzammuhyala/fnftaki). Ini adalah proyek egine sederhana menggunakan framework PyGame yang
berupa gim rhythm dari [Friday Night Funkin'](https://id.wikipedia.org/wiki/Friday_Night_Funkin%27) melawan dan menjadi
karakter bernama [Taki](https://gametoons.fandom.com/wiki/Taki) dari mod
[Friday Night Fever](https://fridaynightfunking.fandom.com/wiki/Friday_Night_Fever). Selain dari mod Friday Night Fever,
terdapat pula versi mod lain yang di cover atau di remix dengan Taki sebagai peran utamanya.
