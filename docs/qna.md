# QnA (Question and Answer)

## Apakah ada fungsi async?
Tidak, dalam PyScript tidak ada teknik async dan await untuk kemudahan implementasi dan kesederhanaan bahasa.

## Apakah ada parameter dan argumen dinamis?
Tidak, parameter dan argumen di Python seperti `*args` maupun `**kwargs` tidak ada sama sekali dalam sintaks PyScript agar pengecekan argument lebih cepat dan mudah diimplementasikan dalam kode inti bahasa.
