# Statements
Berikut ini adalah beberapa daftar sintaks statements dari bahasa pemprograman PyScript.

## Operator Penegasan
Operator penegasan memungkinkan menyimpan nilai ke dalam sebuah variabel.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-identifier">variable</span><span class="c-default"> = </span><span class="c-identifier">expression</span></pre></div>

Ada juga unpacking variabel dimana nilai ekspresi yang berupa _Iterable_ dapat di distribusikan ke beberapa variabel
sekaligus.

sekaligus mengembalikan nilainya dalam satu ekspresi.
