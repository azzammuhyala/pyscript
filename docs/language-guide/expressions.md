# Expressions
Berikut ini adalah beberapa daftar sintaks ekspresi dari bahasa pemprograman PyScript.

## Identifier
Identifier adalah sebuah nama variabel maupun kata kunci. Aturan identifier sama dengan aturan dari Python, tapi dengan
beberapa penambahan berupa simbol prefiks dolar `$` yang berfungsi sebagai penanda bahwa identifier ini murni variabel
dan bukan sebuah kata kunci. Artinya jika ada nama variabel yang berupa kata kunci PyScript, maka parser menggangap itu
variabel biasa.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-keyword">if</span><span class="c-default">      </span><span class="c-comment"># terdeteksi sebagai kata kunci &#x27;if&#x27;</span><span class="c-default"><br></span><span class="c-identifier">$if</span><span class="c-default">     </span><span class="c-comment"># hanya sebagai variabel biasa bernama &#x27;if&#x27;</span><span class="c-default"><br></span><span class="c-identifier">$  else</span><span class="c-default"> </span><span class="c-comment"># prefix $ dapat diikuti spasi lalu identifier kecuali newline</span></pre></div>

## String
PyScript memiliki jenis bentuk string yakni `str` dan `bytes` yang juga ada dalam bentuk string mentahnya. Sintaksnya
juga tidak beda dengan Python.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-string">&#x27;hello&#x27;</span><span class="c-default">                 </span><span class="c-comment"># str: &#x27;hello&#x27;</span><span class="c-default"><br></span><span class="c-string">&quot;hello&quot;</span><span class="c-default">                 </span><span class="c-comment"># str: &#x27;hello&#x27;</span><span class="c-default"><br></span><span class="c-string">&#x27;\&#x27;hello\N{APOSTROPHE}&#x27;</span><span class="c-default"> </span><span class="c-comment"># str: &quot;&#x27;hello&#x27;&quot;</span><span class="c-default"><br></span><span class="c-string">r&#x27;\hello\n&#x27;</span><span class="c-default">             </span><span class="c-comment"># str: &#x27;\\hello\\n&#x27;</span><span class="c-default"><br></span><span class="c-string">b&#x27;\thello\x0a&#x27;</span><span class="c-default">          </span><span class="c-comment"># bytes: b&#x27;\thello\n&#x27;</span><span class="c-default"><br></span><span class="c-string">br&#x27;\hello/&#x27;</span><span class="c-default">             </span><span class="c-comment"># bytes: b&#x27;\\hello/&#x27;</span></pre></div>

> Catatan: Literal bytes menggunakan encoding **latin-1**

## Boolean dan NoneType
PyScript mempunyai kata kunci untuk boolean berupa `True`/`true` dan `False`/`false`. Kemudian ada kata kunci untuk
_NoneType_ dengan `None`/`none`/`null`/`nil`.

## Elipsis
Elipsis di Python biasanya dipakai sebagai placeholder untuk menuliskan kode yang belum diimplementasikan atau belum
selesai. Tapi di PyScript, biasanya menggunakan titik koma `;` untuk itu. Meski demikian, elipsis biasanya dipakai di
beberapa pustaka salah satunya adalah NumPy.

Bentuk sintanks:
<div class="pys-code"><pre><span class="c-keyword-constant">func</span><span class="c-default"> </span><span class="c-identifier-function">notDoneYet</span><span class="c-brackets-0">()</span><span class="c-default"> ...  </span><span class="c-comment"># bisa berupa: func notDoneYet();</span><span class="c-default"><br></span><span class="c-identifier">array</span><span class="c-brackets-0">[</span><span class="c-default">..., </span><span class="c-number">0</span><span class="c-brackets-0">]</span><span class="c-default"> = </span><span class="c-identifier">array</span><span class="c-brackets-0">[</span><span class="c-default">:, :, </span><span class="c-number">0</span><span class="c-brackets-0">]</span></pre></div>

## Kata Kunci `__debug__`
Kata kunci `__debug__` akan menghasilkan nilai boolean berupa flags `DEBUG` atau argumen `-d`/`-O`/`--debug` yang aktif.
Jika aktif atau `True` maka perintah statemen `assert` akan dihiraukan.

## Tuple
Tuple menyimpan daftar terurut secara _immutable_. Artinya setelah tuple dibuat, ia tidak dapat menambah elemen maupun
mengubah nilai elemen dalam tuple. Tuple menggunakan kurung biasa `()` tapi bisa juga hanya dengan karakter koma `,`
saja.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-identifier">primes</span><span class="c-default"> = </span><span class="c-brackets-0">(</span><span class="c-number">2</span><span class="c-default">, </span><span class="c-number">3</span><span class="c-default">, </span><span class="c-number">5</span><span class="c-default">, </span><span class="c-number">7</span><span class="c-default">, </span><span class="c-number">11</span><span class="c-default">, </span><span class="c-number">13</span><span class="c-brackets-0">)</span><span class="c-default"><br><br></span><span class="c-identifier">primes</span><span class="c-default">.</span><span class="c-identifier-function">insert</span><span class="c-brackets-0">(</span><span class="c-number">0</span><span class="c-default">, </span><span class="c-number">1</span><span class="c-brackets-0">)</span><span class="c-default"> </span><span class="c-comment"># error</span><span class="c-default"><br></span><span class="c-identifier">primes</span><span class="c-brackets-0">[</span><span class="c-number">0</span><span class="c-brackets-0">]</span><span class="c-default"> = -</span><span class="c-number">1</span><span class="c-default">      </span><span class="c-comment"># error</span><span class="c-default"><br><br></span><span class="c-identifier">friends</span><span class="c-default"> = </span><span class="c-string">&#x27;Kenny&#x27;</span><span class="c-default">, </span><span class="c-string">&#x27;Kyle&#x27;</span><span class="c-default"><br></span><span class="c-identifier-function">print</span><span class="c-brackets-0">(</span><span class="c-identifier">friends</span><span class="c-brackets-0">)</span><span class="c-default"> </span><span class="c-comment"># (&#x27;Kenny&#x27;, &#x27;Kyle&#x27;)</span></pre></div>

## Set

dihiraukan atau dihapus. Tanda kurung kurawal sebelumnya sudah dipakai di dictionary. Tapi di dictionary, perlu karakter
titik dua `:` sebagai pemisah antara nilai key dan value. Di set, hanya berupa koma `,` atau 1 buah elemen saja seperti
tuple dan list.

## Fungsi
Di PyScript, fungsi adalah ekspresi. Artinya fungsi dapat di definisikan dalam sebuah ekspresi seperti pada kode
berikut:
<div class="pys-code"><pre><span class="c-identifier-function">print</span><span class="c-brackets-0">(</span><span class="c-identifier-function">sorted</span><span class="c-brackets-1">(</span><span class="c-brackets-2">[</span><span class="c-number">5</span><span class="c-default">, </span><span class="c-number">2</span><span class="c-default">, </span><span class="c-number">3</span><span class="c-default">, </span><span class="c-number">1</span><span class="c-default">, </span><span class="c-number">4</span><span class="c-brackets-2">]</span><span class="c-default">, </span><span class="c-identifier">key</span><span class="c-default">=</span><span class="c-keyword-constant">func</span><span class="c-brackets-2">(</span><span class="c-identifier">i</span><span class="c-brackets-2">)</span><span class="c-default"> =&gt; </span><span class="c-number">5</span><span class="c-default">-</span><span class="c-identifier">i</span><span class="c-brackets-1">)</span><span class="c-brackets-0">)</span><span class="c-default"> </span><span class="c-comment"># [5, 4, 3, 2, 1]</span></pre></div>

maupun sebagai fungsi sederhana seperti `lambda` pada Python.

diisi saat pemanggilan. Jika tidak, maka akan melempar `TypeError`. Parameter optional berupa identifier diikuti dengan

Di fungsi terdapat operator `=>` yang terlihat seperti arrow function pada JavaScript, operator `=>` ini sama seperti 
statement `return`. Artinya bahwa operator ini hanya menyingkat kode dengan kata kunci `return ...` menjadi `=> ...`.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-comment"># sama seperti func add(a, b) return a + b</span><span class="c-default"><br></span><span class="c-keyword-constant">func</span><span class="c-default"> </span><span class="c-identifier-function">add</span><span class="c-brackets-0">(</span><span class="c-identifier">a</span><span class="c-default">, </span><span class="c-identifier">b</span><span class="c-brackets-0">)</span><span class="c-default"> =&gt; </span><span class="c-identifier">a</span><span class="c-default"> + </span><span class="c-identifier">b</span><span class="c-default"><br><br></span><span class="c-identifier-function">print</span><span class="c-brackets-0">(</span><span class="c-identifier-function">add</span><span class="c-brackets-1">(</span><span class="c-number">1</span><span class="c-default">, </span><span class="c-number">1</span><span class="c-brackets-1">)</span><span class="c-brackets-0">)</span><span class="c-default"> </span><span class="c-comment"># 2</span></pre></div>

Selain `func` atau `function`, PyScript memiliki fungsi dengan kata kunci `constructor`. Fungsi dengan kata kunci ini
hanya digunakan pada definisi kelas (`class`) sebagai fungsi initialisasi atau constructor. Jadi fungsi `constructor`
sebenarnya adalah fungsi yang mendefinsikan dirinya bernama `__init__` dan parameter `self`.
