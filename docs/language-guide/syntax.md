# Syntax

Disini Anda akan mempelajari beberapa sintaks yang ada di PyScript.

## Komentar
Komentar membantu untuk menjelaskan cara dan alur kode dan memberikan beberapa catatan untuk pengembangan kode. Komentar
di awali dengan tanda pagar `#` dan berakhir pada karater newline.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-comment"># Kode program Hello World untuk pemula</span><span class="c-default"><br><br></span><span class="c-identifier-function">print</span><span class="c-brackets-0">(</span><span class="c-string">&#x27;Hello World!&#x27;</span><span class="c-brackets-0">)</span><span class="c-default"> </span><span class="c-comment"># mencetak kata &quot;Hello World!&quot; ke terminal</span><span class="c-default"><br></span><span class="c-identifier-function">print</span><span class="c-brackets-0">(</span><span class="c-number">1</span><span class="c-default"> + </span><span class="c-number">1</span><span class="c-brackets-0">)</span><span class="c-default">          </span><span class="c-comment"># ini menghasilkan 2 di terminal</span></pre></div>

## Identifier
Identifier adalah sebuah nama variabel maupun kata kunci. Aturan identifier sama dengan aturan dari Python tapi dengan
beberapa penambahan berupa simbol prefiks `$` yang berfungsi sebagai penanda bahwa identifier ini murni variabel dan
bukanlah kata kunci. Artinya jika nama variabel berupa kata kunci yang ada di PyScript, maka parser menggangap itu
variabel.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-keyword">if</span><span class="c-default">      </span><span class="c-comment"># terdeteksi sebagai kata kunci &#x27;if&#x27;</span><span class="c-default"><br></span><span class="c-identifier">$if</span><span class="c-default">     </span><span class="c-comment"># hanya sebagai variabel biasa bernama &#x27;if&#x27;</span><span class="c-default"><br></span><span class="c-identifier">$  else</span><span class="c-default"> </span><span class="c-comment"># prefix $ dapat diikuti spasi lalu identifier kecuali newline</span></pre></div>

## String
PyScript memiliki 2 jenis bentuk string yakni `str` dan `bytes`. Sintaksnya juga tidak beda dengan Python.

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-string">&#x27;hello&#x27;</span><span class="c-default">                 </span><span class="c-comment"># str: &#x27;hello&#x27;</span><span class="c-default"><br></span><span class="c-string">&quot;hello&quot;</span><span class="c-default">                 </span><span class="c-comment"># str: &#x27;hello&#x27;</span><span class="c-default"><br></span><span class="c-string">&#x27;\&#x27;hello\N{APOSTROPHE}&#x27;</span><span class="c-default"> </span><span class="c-comment"># str: &quot;&#x27;hello&#x27;&quot;</span><span class="c-default"><br></span><span class="c-string">r&#x27;\hello/&#x27;</span><span class="c-default">              </span><span class="c-comment"># str: &#x27;\\hello/&#x27;</span><span class="c-default"><br></span><span class="c-string">b&#x27;hello&#x27;</span><span class="c-default">                </span><span class="c-comment"># bytes: b&#x27;hello&#x27;</span><span class="c-default"><br></span><span class="c-string">br&#x27;\hello/&#x27;</span><span class="c-default">             </span><span class="c-comment"># bytes: b&#x27;\\hello/&#x27;</span></pre></div>

> Note: Literal bytes menggunakan encoding **latin-1**

## Assignment Expressions
Assignment memungkinkan menyimpan nilai ekspresi ke dalam sebuah variabel

Bentuk sintaks:
<div class="pys-code"><pre><span class="c-identifier">variable</span><span class="c-default"> = </span><span class="c-identifier">expression</span></pre></div>
