# Atom
Bagian ini adalah level tertingi operasi yang berisi kata kunci konstant, literal, identifier, kurung, list, dict, set, dan tuple.

## Kata Kunci Konstant
- Boolean (`True`, `true`, `False`, `false`)
- None (`None`, `none`, `null`, `nil`)
- Debug (`__debug__`): Berupa boolean dan menghasilkan True jika flags [DEBUG](../../packages/pyscript-python-packages/constants.md#debug) aktif.
- Elipsis (`...`)
